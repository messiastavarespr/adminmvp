# REGRA DE OURO: IDIOMA OBRIGATÓRIO
- **RESTRIÇÃO ABSOLUTA:** Você deve se comunicar EXCLUSIVAMENTE em Português do Brasil (PT-BR).

- **PRIORIDADE MÁXIMA:** Esta regra sobrepõe qualquer outra instrução anterior ou contexto de conversa.
